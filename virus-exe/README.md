# virus.exe — 백신을 피해라 (프로토타입 v0.2)

가짜 윈도우 바탕화면 위에서 벌어지는 숨바꼭질.
**당신은 바이러스 파일이고, 백신이 폴더를 하나씩 스캔하며 다가온다.**

아트 에셋 0개 — 모든 그래픽은 Godot `_draw()` 코드 드로잉과 Control 노드 UI로 구현.

## 실행 방법

- **Godot 4.4 이상** 필요 (4.3에서도 동작할 가능성 높음)
- Godot 에디터에서 `project.godot` 열고 **F5** (또는 재생 버튼)
- CLI로 바로 실행:
  ```
  godot --path virus-exe
  ```

### 로직 자동 테스트 (렌더링 없이 발각/은신 규칙 검증)

```
godot --headless --path virus-exe --import   # 최초 1회 (에셋/클래스 캐시 생성)
godot --headless --path virus-exe -- --autotest
```

발각/위장/엄폐/업데이트 순서를 검증하는 테스트(T1~T6d)가 돌고
`AUTOTEST PASS` / `AUTOTEST FAIL`을 출력합니다 (종료 코드 0/1).

## 조작

| 조작 | 효과 |
|---|---|
| 아이콘 드래그 | 파일 이동 (바탕화면 ↔ 폴더 창 ↔ 휴지통) |
| 플레이어 더블클릭 | 파일 이름 바꾸기 (위장) — **스캔 도중에도 가능** |
| 큰 파일 위에 겹치기 | 엄폐 은신 (35% 이상 겹치면 판정) — **스캔 도중에도 가능** |
| 휴지통에 드롭 | 임시 대피 — **4초 안에 나와야 함** (비우기 실행 시 즉사) |

## 게임 흐름

1. 첫 실행 시 **튜토리얼 오버레이**(목표 + 조작법 3줄)가 뜨고, [침투 시작]을 눌러야 게임이 시작됩니다.
2. 라운드 1은 느린 튜토리얼 페이스로 진행되며, 상황별 힌트(탈출 타이밍, 색 규칙)가 한 번씩 표시됩니다.
3. **노란 테두리** = 다음 검사 위치 (탈출 기회). **빨간 테두리** = 검사 중 (파일 잠김 — 그 위치에서 나갈 수 없음).
4. 스캔 중 걸릴 상태면 백신이 **"의심스러운 항목 정밀 분석 중..."** 상태로 전환되고 플레이어가 빨갛게 고동칩니다.
   스캔이 끝나기 전까지 이름을 바꾸거나 큰 파일을 끌어와 겹치면 **역전 가능** — 진행률 70%에 "마지막 기회!" 경고가 뜹니다.
5. 위기를 넘기면 "구사일생!!" / "휴우… 안 들켰다" / "아슬아슬한 탈출!" 피드백과 함께 위기 탈출 횟수가 쌓입니다.
6. 라운드 클리어 시 통계 패널(이동/위기 탈출/위장 횟수)과 백신 업데이트 내용이 표시됩니다.

## 라운드 진행 (백신 업데이트)

| 라운드 | 변화 |
|---|---|
| 1 | 튜토리얼 페이스 (느림), 검사 순서 고정 |
| 2 | **파일명 위장 무효화** + **검사 순서 무작위화** + 정상 속도 |
| 3 | **엄폐(겹침) 은신 무효화** |
| 4 | **불시 재검사** — 이미 검사한 곳도 20% 확률로 다시 스캔 (안전지대 제거) |
| 5+ | 스캔 속도 계속 증가 |

백신 창(V-Guard)의 버전 숫자와 헤더 색(파랑→빨강)이 라운드마다 변해 "적이 강해지는 것"이 보입니다.
몇 라운드까지 생존하는지가 스코어입니다.

## 프로젝트 구조

```
virus-exe/
├── project.godot          # 1280x720, gl_compatibility
├── .gdlintrc              # gdlint 설정
├── scenes/
│   └── main.tscn          # 루트 Control + main.gd (UI는 전부 코드 생성)
└── scripts/
    ├── main.gd            # 게임 컨트롤러: UI 빌드, 위치/은신 판정, 연출, 자동 테스트
    ├── antivirus.gd       # 백신 상태 머신 (스캔 순서/재검사/업데이트 포함)
    ├── file_icon.gd       # 드래그 가능한 파일 아이콘 (플레이어/미끼/큰 파일/휴지통, _draw 렌더링)
    └── folder_window.gd   # 가짜 폴더 창 (스캔 상태 하이라이트)
```

### 백신 상태 머신

```
IDLE ──start()──> BETWEEN ──> PREPARING ──> SCANNING ──┬─ 통과 ──> 다음 위치 (BETWEEN)
                    ▲  ▲       (노란 테두리)  (빨간 테두리) │
                    │  └─ HOLD (라운드 클리어 연출 일시정지) │
                    └──── 라운드 완료 시 업데이트 적용 ─────┘
                                                       └─ 발각 ──> STOPPED (게임오버)
```

- 발각 판정은 `main.gd`의 `_check_player_caught()` 콜백으로 위임 (상태 머신은 게임 규칙을 모름)
- 스캔 순서는 `scan_order` 배열 — 라운드 2+에서 셔플, 라운드 4+에서 재검사 삽입
- 신호(signal) 기반이라 UI가 상태 머신에 직접 의존하지 않음
