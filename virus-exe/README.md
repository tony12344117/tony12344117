# virus.exe — 백신을 피해라 (프로토타입)

가짜 윈도우 바탕화면 위에서 벌어지는 숨바꼭질.
**당신은 바이러스 파일이고, 백신이 폴더를 하나씩 스캔하며 다가온다.**

아트 에셋 0개 — 모든 그래픽은 Godot `_draw()` 코드 드로잉과 Control 노드 UI로 구현.

## 실행 방법

- **Godot 4.4 이상** 필요 (4.3에서도 동작할 가능성 높음)
- Godot 에디터에서 `project.godot` 열고 **F5** (또는 재생 버튼)
- CLI로 바로 실행:
  ```
  godot --path virus-exe
  ```

### 로직 자동 테스트 (렌더링 없이 발각/은신 규칙 검증)

```
godot --headless --path virus-exe --import   # 최초 1회 (에셋/클래스 캐시 생성)
godot --headless --path virus-exe -- --autotest
```

6개 테스트가 돌고 `AUTOTEST PASS` / `AUTOTEST FAIL`을 출력합니다 (종료 코드 0/1).

## 조작

| 조작 | 효과 |
|---|---|
| 아이콘 드래그 | 파일 이동 (바탕화면 ↔ 폴더 창 ↔ 휴지통) |
| 플레이어 더블클릭 | 파일 이름 바꾸기 (위장) |
| 큰 파일 위에 겹치기 | 엄폐 은신 (35% 이상 겹치면 판정) |
| 휴지통에 드롭 | 임시 대피 — **4초 안에 나와야 함** (비우기 실행 시 즉사) |

## 규칙

- 백신(V-Guard)은 `바탕화면 → 내 문서 → 다운로드 → 사진` 순서로 스캔합니다.
- **스캔이 시작된 위치에서는 파일을 옮길 수 없습니다** (파일 잠김). 노란 테두리(준비 단계)가 마지막 탈출 기회입니다.
- 스캔이 끝나는 순간 그 위치에 있으면, 아래 중 하나가 성립해야 살아남습니다:
  - 파일명이 평범한 문서/사진처럼 보임 (예: `휴가사진.jpg`)
  - 큰 파일(영화_4K.mp4, 백업.zip) 뒤에 숨어 있음
  - 휴지통 안에 있음 (스캔 대상 아님)
- 한 라운드(전체 스캔)를 버틸 때마다 백신이 **업데이트**됩니다:
  - **라운드 2**: 시그니처 DB 갱신 → 파일명 위장 무효화
  - **라운드 3**: 휴리스틱 스캔 → 엄폐 은신 무효화
  - **라운드 4+**: 스캔 속도 계속 증가 → 이동 타이밍과 휴지통 순환만 남음
- 몇 라운드까지 생존하는지가 스코어입니다.

## 프로젝트 구조

```
virus-exe/
├── project.godot          # 1280x720, gl_compatibility
├── scenes/
│   └── main.tscn          # 루트 Control + main.gd (UI는 전부 코드 생성)
└── scripts/
    ├── main.gd            # 게임 컨트롤러: UI 빌드, 위치 판정, 라운드/게임오버, 자동 테스트
    ├── antivirus.gd       # 백신 상태 머신 (IDLE→BETWEEN→PREPARING→SCANNING→…)
    ├── file_icon.gd       # 드래그 가능한 파일 아이콘 (플레이어/미끼/큰 파일/휴지통, _draw 렌더링)
    └── folder_window.gd   # 가짜 폴더 창 (스캔 상태 하이라이트)
```

### 백신 상태 머신

```
IDLE ──start()──> BETWEEN ──> PREPARING ──> SCANNING ──┬─ 통과 ──> 다음 위치 (BETWEEN)
                     ▲          (노란 테두리)  (빨간 테두리) │
                     │                                 └─ 발각 ──> STOPPED (게임오버)
                     └──── 라운드 완료 시 업데이트 적용 ────┘
```

- 발각 판정은 `main.gd`의 `_check_player_caught()` 콜백으로 위임 (상태 머신은 게임 규칙을 모름)
- 신호(signal) 기반이라 UI가 상태 머신에 직접 의존하지 않음
